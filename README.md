# Soft Landing Lab

**[Play Soft Landing Lab](https://xanderwasserman.github.io/soft-landing-lab/)**

A first-principles 2D soft-landing toy in the browser. A hopper falls in a vertical plane under Earth gravity and lands by thrust alone.

## Controls

- **Space** (hold): throttle
- **A / D** or **Left / Right**: gimbal
- **R**: reset

## Local

Open `index.html` in a browser. There is no build step.

The force law and numbers are in [DESIGN.md](DESIGN.md).
